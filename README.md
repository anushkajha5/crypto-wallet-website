# Crypto Wallet (Demo) — informational website

This is **not** a web wallet. The project is **not** App Store submission-ready until legal copy, privacy practices and the real App Store URL are confirmed, and the site is deployed on HTTPS.

See `docs/OWNER_HANDOVER.md` and `docs/PRIVACY_POLICY_OWNER_CHECKLIST.md`.

```bash
npm install
npm run dev
npm run build
```

Configure branding and the App Store URL in `src/config/site.ts`.
